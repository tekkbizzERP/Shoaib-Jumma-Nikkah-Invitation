# Nikah Invitation Website: Shoaib & Zubia

## GitHub par live karne ka tareeqa (5 minute)
1. github.com par login karein, phir **New repository** banayein. Naam rakhein `nikah` aur **Public** select karein.
2. **Add file → Upload files** par jayein aur teeno files ek saath drag karein: `index.html`, `couple.jpg`, `nasheed.mp3`. Phir **Commit**.
3. Repo ke **Settings → Pages** mein jayein. Source: **Deploy from a branch**, Branch: **main**, folder **/(root)**, phir **Save**.
4. 1–2 minute baad link mil jayega: `https://YOUR-USERNAME.github.io/nikah/`
5. Yahi link QR code mein daalna hai.

## Files
- `index.html`: poori website
- `couple.jpg`: dulha dulhan ki illustration
- `nasheed.mp3`: background nasheed (chaabi tap karte hi chalti hai, neeche right mein on/off button)

## Kuch badalna ho
`index.html` mein text seedha edit kar sakte hain. Countdown ka time `const EVENT = ...` wali line mein hai (abhi 08 Jan 2027, 4:00 PM).
